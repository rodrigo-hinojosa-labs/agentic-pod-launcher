**Tests**: MANDATORY (constitution Principle III — test-first). Every behaviour task is preceded by a RED bats task. Negative assertions use bats-live forms (`run grep -q …; [ "$status" -ne 0 ]` or `[ "$(grep -c … || true)" -eq 0 ]`), never a bare intermediate `! grep`. `grep -c` under `set -e` inside container scripts needs `|| true` (033 harness lesson).

**Organization**: Tasks are grouped by user story. All plugin behaviour lives in ONE file (`docker/scripts/apply_telegram_typing_patch.py`) whose v3 helpers depend on each other (the assembler needs the normalizer, the cut and the sign-off helpers), so the story phases are ordered by that dependency chain — **US1 → US3 → US2 → US4** — not by priority. Priorities still hold for scope: nothing ships without US1+US2 (P1); the four stories ride one PR and one deploy (033 precedent). Each phase is still independently RED→GREEN on the host.

**Line numbers**: `:NNN` references are PRE-T003 and only locate tests; from T003 on, find existing tests by their `@test` NAME, quoted below. Canonical strings that MUST be identical between a test task and its implementation task are marked **CANON**.

**Literal rules (research D14)**: every TS backslash is doubled in the Python literal; every `re.subn` replacement is a `lambda`; the sequences `\u0300-\u036f`, `\u2026`, `\u{1F1E6}-\u{1F1FF}`, `\u{1F3FB}-\u{1F3FF}`, `\u{20E3}`, `\u{FE0F}`, `\u{200D}` are typed as escape TEXT — verify byte-for-byte after every edit (`LC_ALL=C grep -c $'\xcc\x80' FILE` = 0); Python's VALID escapes (`\1 \b \t \r \n …`) transform silently, so G15/G16 (T009/T011) exist. Regex source form (analyze I2): the figure group is `/…/.source` and the symbol rules are `String.raw` template literals — ONE backslash in the TS text, two in the Python literal; a plain JS string (doubled backslashes in the TS) is forbidden because every one-backslash oracle would go RED against a correct implementation.
