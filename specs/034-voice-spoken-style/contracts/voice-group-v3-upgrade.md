## C2. `upgrade_voice_v2_to_v3(src) -> (str, bool)`

```python
def upgrade_voice_v2_to_v3(src: str) -> tuple[str, bool]:
    if MARKER_VOICE_V2 not in src:
        return src, False
    pairs = [
        (VOICE_HELPERS_V2, VOICE_HELPERS),
        (VOICE_REPLY_BLOCK_V2, VOICE_REPLY_BLOCK),
        (VOICE_SCHEMA_PROPERTY_V2, VOICE_SCHEMA_PROPERTY),
        (VOICE_INSTRUCTIONS_LINE_V2, VOICE_INSTRUCTIONS_LINE),
    ]
    work = src
    for old, new in pairs:
        if work.count(old) != 1:
            warn("voice v2→v3 upgrade: a v2 constant is missing or duplicated — leaving the voice group at v2")
            return src, False
        work = work.replace(old, new, 1)
    return work, True
```

All-or-nothing, `str.replace` (no regex, no escape processing), returns the ORIGINAL on any
miss. Each `old` MUST be the exact byte string the v1→v2 upgrader / the v0.24.0 fresh apply
wrote (guaranteed by the `_V2` twins being verbatim copies, checked by the golden fidelity
test).

## C7. Rollback note

Reverting the image to v0.24.0 does NOT downgrade a v3 plugin file: the v0.24.0 patcher sees
`MARKER_VOICE` (v3 string ≠ its v2 string) as "unknown", finds no v1 marker either, tries a
fresh apply, fails hunk 2/3 anchors (already rewritten), WARNs and leaves v3 intact and
functional. To truly downgrade, delete the plugin cache directory and let the boot reinstall + re-patch (033 quickstart §4 procedure).
